# Telos

> Ship eidos-cli v1.0 — the unified agent CLI for the Eidos scope architecture, per THE-EIDOS doctrine and ADR-007

## What success looks like

- eidos define/enter/status/activate/close work end-to-end with the four-field telos contract gate
- eidos research/governor/docket/praxis namespaces route to the five forge libraries
- eidos mcp serve boots a razor-thin help-only MCP server
- eidos migrate consolidates legacy .telos/.research/.governor/.docket/.hone into a single .eidos/ idempotently
- eidos spawn promotes a docket item to a child eidos
- eidos tick emits drift classification against the telos triggers

## What failure looks like

- doctrine in THE-EIDOS and code in eidos-cli diverge silently
- the migration corrupts existing consumer state
- Solo-default is bypassed in favor of unconditional Pod-default

## What this eidos refuses to become

- becomes a chat-mode conversational assistant
- duplicates the five forge libraries' internal logic
- couples eidos to a single LLM provider
- imposes ceremony on tasks an AI can do in one pass
